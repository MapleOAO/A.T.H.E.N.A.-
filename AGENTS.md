# A.T.H.E.N.A. agent handoff rules

Read README.md, docs/ARCHITECTURE.md, docs/DATA_POLICY.md and docs/HANDOFF.md before editing.

Before new research, consult docs/research/README.md and docs/REMAINING.md. Reuse recorded page scopes, identity evidence and held findings instead of repeatedly searching already-reviewed material. Downloaded but unread pages are not evidence.

- Independent code only. Never copy Atlas application code, styles, coordinates or assets.
- Atlas factual records are allowed as attributed candidate inputs, not automatically canonical facts.
- Keep original Atlas version, JSON pointer and names. Never hide attribution after official corroboration.
- Chinese output must resolve entity IDs through data/glossary.json; unknown terms stay pending. No invented official translations.
- A verified relation requires a read, supporting official source, a locator, an independently written summary, a review date and translation provenance. A URL alone is not evidence.
- Do not infer memberships/enmities from graph edges or layout junctions. Distinguish historic periods from present status.
- Do not erase user edits, force push, clear repositories or deploy externally without user authorization.
- No Sites. The repository is the durable source of truth. No API credentials or secret tokens in this project.
- No fabricated accounts, database, automatic crawlers, AI translation service or public deployment claims.
- Run npm run validate, npm test and npm run build. Test UI if a browser is reachable; disclose limitations honestly.
- Source data lives in data/, implementation in src/ and web/, tooling in scripts/. Never manually edit dist/.
- Update docs/HANDOFF.md and CHANGELOG.md for material changes, including known limitations and next exact steps.
