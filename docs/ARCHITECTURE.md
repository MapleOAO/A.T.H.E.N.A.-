# 架构与设计取舍

## 决策记录 ADR-001：先建立可核验的垂直切片

首版采用 Node.js ESM、原生 DOM 和 SVG。没有框架、外部字体、第三方脚本或运行时依赖。后续版本加入有来源记录的官方CDN图片引用。好处是后续 Agent 能直接启动并理解数据流，且无需配置用户服务器或付费服务。

知识库以多份 JSON 在 Git 中版本化，是当前真实的持久化层。少量结构化 JSON 本身不是质量问题，关键在约束、证据和审核。本版不假装存在数据库；多用户写入、全文检索或大规模更新出现时再迁移到数据库。

## 数据流

Atlas v5 本地文件 → blob SHA 验证 → 白名单字段转换 → 待核验候选 → 官方来源证据 + 术语库 → 人工／Agent 审阅的正式关系 → 校验 → 静态构建 → 浏览器。

- 导入器不发送网络请求，不能直接改正式数据。
- `sources` 管出处；`candidates` 管输入血缘；`relations` 管具体主张；`glossary` 管中文词汇。
- Atlas 的 `edges` 是排版连线，不能判定方向、敌对、隶属等语义。`junction` 永不变成角色。
- 官方核验后仍保留 Atlas 候选引用，不删除上游贡献。
- `Talon Empire` 不自动映射为 `Talon`；近似名称合并需要独立实体消歧。

## 前端

`web/app.mjs` 只消费 `data/knowledge.json` 和 `src/knowledge.mjs`。开发服务动态拼装相同数据；构建脚本将其输出到 `dist/data/knowledge.json`。

用 `textContent` 安全插入资料文字，不通过 innerHTML 执行上游内容。外部链接仅允许无凭据 HTTPS。图谱通过 SVG path 绘制原创曲线；layout.mjs 按连通分量确定性分组、分环并排布，孤立节点独立排列，不读取 Atlas 坐标。默认一跳聚焦，目录不受聚焦限制；全图可缩放到800%。颜色仅为布局分组，不编码当前组织成员身份。

查询按边的状态／时期／谓词过滤，再形成无悬空端点的子图。搜索匹配中文、英文和别名，显示匹配实体的一跳邻接。类型筛选保留两端均匹配的关系。实体 ID 与关系 ID 可放入 URL hash；筛选条件暂不分享。

## 只读 API（仅本地开发服务）

| GET / HEAD | 返回 |
| --- | --- |
| `/api/health` | 状态和版本 |
| `/api/graph` | 完整首批知识库，与静态数据一致 |
| `/data/knowledge.json` | 前端统一数据入口 |
| `/api/entities/:id` | 实体与关联关系；未知 ID 返回 404 |

其他方法返回 405。只服务 web/src 白名单目录，真实路径校验防止跨目录读取；不暴露 `.git`、`.env`、脚本或配置。CSP 禁止第三方脚本与内联脚本。静态托管不包含 API，前端不依赖 API 路由。

## 扩展顺序

1. 稳定数据模型、核验真实关系并补齐中文术语。
2. 引入 JSON Schema 或类型系统，保留现有跨引用校验与回归测试。
3. 官方网页采集适配器（先许可／robots 检查、限速、失败记录），再考虑生成式中文摘要。
4. 新增时间区间、多证据冲突与版本撤回；不要用单个 currentFaction 覆盖历史。
5. 数据规模增长时引入 SQLite 或其他数据库，前端仍消费投影数据。
6. 用户已授权 GitHub Pages。main 保存源码，gh-pages 保存静态产物；首次启用依赖仓库 Pages 设置。没有 Sites / Vercel / 用户服务器资源。

## v0.4 图像

人物头像、剧情配图、组织标志、名称占位四种visual类型分别校验。剧情配图需要身份说明，局部展示需要原图尺寸及界内坐标。列表和详情使用原生SVG视窗，图谱使用同一crop数据；详情保留全图与图源。失效图像回退到名称。收录进度提供按实体类型及缺图状态筛选的图像目录。

## v0.5 可追溯图像局部

official-excerpt为本地JPEG局部引用，visual.extraction保存原PDF哈希、页码、缩放基准、提取区域和JPEG哈希。scripts/assets.mjs检查路径、文件格式和哈希；构建先校验后复制web资源。离线版嵌入已核对图片映射，运行时统一imageUrl读取；原知识库仍保留相对路径及完整溯源数据。新增researched受控关系只表示研究对象，不代替创造、亲属或合作关系。

## v0.6 实体核对说明

实体可带researchNote，必须有已读官方来源、页码、独立摘要和复核日期。详情在关系列表之前展示，能说明上游类别或名字的歧义，同时保留原始输入。构建在数据及图像哈希校验通过后清理dist，防止已撤回图片遗留在发布目录。

## v0.9.1 招募事件

recruited-for为人物→组织关系，表示明确为该组织招募人员的事件，不等同于member或leader。沿用证据、译名和Atlas候选血缘验证，界面从受控词表自动生成筛选与关系短句。

## v0.9.2 连线交互

routeRelations在布局后计算曲线。按无向端点分组、稳定排序，多关系分道；对候选弯曲程度采样并减少节点与控制点遮挡，密集全图仍可有交叉。曲线鼠标命中与圆点按钮分开，圆点有名称、选中状态、键盘操作，重绘后恢复键盘焦点。选中关系不重复计算路由。

## v0.10.0 官方发现来源

实体必须有Atlas origins或官方discovery。discovery包含sourceId、locator、reviewedAt，只接受已读官方源。新实体不伪造Atlas指针。既有Talon补录官方来源，独立收录统计为5项。
