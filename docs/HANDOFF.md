# 下一位 Agent 从这里开始

## 用户要求

从零建设 A.T.H.E.N.A.；不使用 Atlas 代码，但使用其资料构建我们自己的中文人物与组织关系网络。中文基于我们沉淀的知识库。项目保存在 `MapleOAO/A.T.H.E.N.A.-`。不使用 Sites，不使用用户服务器，不再次清空仓库。

## 已完成（v0.1.0 / 2026-09-18）

- 独立 Node.js / SVG 项目，无依赖，`npm run dev` 即可运行。
- 数据：18 实体，21 关系（17 已核验 / 4 待核验），7 来源，18 术语（17 官方中文已对齐 / 1 暂译）。
- 实际读取 Atlas `codex-labels.json` v5：1216 nodes / 1430 edges / 57 connections。不是 1216 人物；含大量 junction。
- 从 `connections[0..7]` 整理 8 组安娜相关事实端点。4 组已独立核验具体关系，4 组待核验。
- Atlas commit `7df0623bf538ef5dedd49e620fc7a6356f5318d2`；文件 blob `c52b9ff73955ca9bf4d5fd1d83a0fd589718df0b`。
- 官方来源通过实际可见正文核对。关系证据有 source ID、章节、中文概括、审核日期。没有保存原文全文。
- 原创关系图，查询／筛选、聚焦、缩放／平移、键盘节点与边、证据面板、术语库、来源列表、只读待核验队列。
- 独立导入适配器仅输出候选，不自动发布；中文化 CLI 仅生成受控关系短句。
- 32 项 Node 自动化测试通过；数据校验、JS 语法检查、静态构建通过。

## 真实限制（不要夸大）

- 首批样本不是完整 Atlas 数据或全量世界观知识库。
- 没有后台数据库、多用户写入、自动爬虫、LLM 翻译、完整事件时间线或媒体资产。
- 没有生产部署。GitHub 仓库链接不是可运行网站链接。
- 本轮云浏览器访问 `http://127.0.0.1:3000` 被 `ERR_BLOCKED_BY_CLIENT` 拒绝。未完成真实界面截图、交互和移动端视觉检查。自动化数据与 HTTP 测试不等同视觉验收。
- 三个组织名称已用官方中文传记核对；Search & Rescue 暂译待审。
- 本轮仅核对指定历史章节，不宣称最新赛季全量准确。
- 未声明开源许可证；批量复制上游原文或资产之前应解决权利问题。

## 立即接手步骤

1. 阅读 AGENTS.md、ARCHITECTURE.md、DATA_POLICY.md、DATA_MODEL.md。
2. 运行 `npm run validate && npm test && npm run build`。
3. 在可访问开发服务的浏览器打开 127.0.0.1:3000，按 VERIFY.md 完成界面验收，特别检查缩放、窄屏、键盘选择以及无结果状态。
4. 逐条核验 Ana ↔ Emre / Reaper / Reinhardt / Search & Rescue。不要仅因同处早期战队就自动定义所有时期关系。
5. 补充新实体时先建 glossary，保留官方名字出处；通过 importer unresolved 报告驱动新词审核。
6. 在不改变出处和审核约束的前提下扩充其他人物、组织和关系。把新增来源及状态变更写入 CHANGELOG。
7. 如需公开网页，先与用户确认托管方式，再部署 `dist/`。不得自行改用 Sites。

## 不应该做的事情

- 不将 Atlas 中的 junction／任意边当成明确剧情事实。
- 不把 `Talon Empire` 自动重命名为 `Talon`。
- 不用翻译掩盖资料原始来源，不把 AI 审核写成人工审核。
- 不因为 JSON 文件存在就声称不适合长期维护；先根据并发、查询、规模决定迁移。
- 不把上一轮对 Atlas 的“没有 schema/不成熟”等推断当成已证实结论。
